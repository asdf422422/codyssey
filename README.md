## 1. 프로젝트 개요
개발자가 자주 쓰는 터미널 및 Docker, 깃허브 설정 방법 알아보기

- 터미널로 디렉토리 및 파일 관리하기 
- Docker 설치 및 기본 운영 명령 습득하기
- Dockerfile 기반 커스텀 이미지 제작
- Git과 GitHub 사용 방법을 익히기

최종적으로 같은 서비스를 여러 번 다른 컴퓨터에서 실행해도 재현되는 사고방식을 익히기
<br>
